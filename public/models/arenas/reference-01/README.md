# Arena de referencia 01

Original suministrado por el usuario, exportado desde SketchUp en metros. Los archivos OBJ y MTL se conservan sin modificaciones.

- Base: X=[0,25], Y=[-1,0], Z=[-25,0].
- Barrera central: X=[7,18], Y=[0,4], Z=[-13,-12].
- Traslación aplicada en ejecución: X=-12.5, Y=0, Z=+12.5.
- Base centrada resultante: X/Z=[-12.5,+12.5], superficie Y=0.
- Barrera resultante: centro (0,2,0), tamaño 11×4×1 m.

El motor importa la barrera del OBJ. La base visual se representa con 625 cubos de 1×1×1 m para conservar el requisito de módulos del proyecto. La colisión utiliza una base, cuatro paredes perimetrales añadidas por el motor y una caja para la barrera. El MTL original contiene un material blanco, sin texturas externas; la vista aplica una paleta provisional.

Mantén aquí los originales de esta arena. Usa otra carpeta bajo `arenas/` para una arena distinta. Para Blender, preferir GLB con metros, Y vertical, suelo Y=0 y origen centrado.
